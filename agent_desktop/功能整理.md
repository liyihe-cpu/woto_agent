# Agent 功能整理与需求模板

## 你向 Agent 提需求时，它应完成什么

1. 理解自然语言、附件中的条件和国家简称。
2. 将国家转换为 ISO 两位代码，并严格保留你写出的先后顺序。
3. 输出并执行标准采集计划：平台、国家、粉丝范围、初始跨度、发布时间。
4. 每个国家使用两种合适的语言采集。
5. 单个查询达到 10,000 条时，自动细分范围：`1w → 5k → 1k → 500 → 250 → 二分`。
6. 在唯一聊天窗显示方案、运行状态、实时日志、错误与完成状态。
7. 将 CSV 写入 `wotohub_collector/output/<platform>/<country>/`。

## 模型必须输出的格式

模型只输出以下 JSON，不输出 Markdown、解释或额外字段：

```json
{
  "platform": "youtube",
  "countries": ["gb", "fr", "de", "it", "es"],
  "follower_min": 2000,
  "follower_max": 300000,
  "span": "5k",
  "recent": 30
}
```

`countries` 数组顺序就是实际采集优先级。`follower_min` 包含，`follower_max` 不包含。

## 推荐的需求写法

```text
英法德意西优先，YouTube，粉丝 2k–300k，近 30 天，初始跨度 5k。
```

也可附上目标客户画像、竞品名单、表格或图片；在聊天区拖入文件，或复制后在输入框按 `Ctrl+V`。

## 需要的工具

当前流程不需要再接入额外的 Agent tool：

| 能力 | 已使用组件 |
| --- | --- |
| 需求理解、国家翻译、计划 JSON | SiliconFlow 的 OpenAI 兼容模型接口 |
| WotoHub 查询与 handle 导出 | 现有 `vue_full_collector.py` |
| 已登录浏览器会话 | Edge + Playwright CDP（`127.0.0.1:9222`） |
| 表格、文本附件读取 | Python + openpyxl |
| 拖拽、复制文件 | Tkinter + tkinterdnd2 |

只有在以下需求出现时才需要新增工具：实时市场/新闻检索、外部 CRM 或 Airtable 写入、自动上传云盘、发送邮件或 Slack 通知。
